# 個人情報マスキングツール（使い方）

操作録画やスクショをAIに渡す前に、映り込んだ個人情報を自動で塗りつぶすツールです。
**すべてこのMacの中で処理し、動画も文字も外部には送りません。**

## 使い方（毎回）

1. `start.command` をダブルクリック
   （初回だけ「開発元が未確認」と出たら、右クリック →「開く」）
2. ブラウザで画面が開く（開かなければ http://127.0.0.1:8765 ）
3. 動画・画像をドラッグ＆ドロップ（複数まとめてOK）
4. 終わったら「ダウンロード」→ 中身をざっと確認してからAIへ
5. 終了するときは、黒い画面（ターミナル）を閉じる

## 何を隠すか

| 項目 | 例 |
|---|---|
| 電話番号 | 090-1234-5678 / 03-5555-1234 |
| メールアドレス | 入力途中の `suzuki@te` も隠す |
| 住所・郵便番号 | 東京都渋谷区…／150-0041 |
| 長い番号 | カード番号・マイナンバー・会員番号 |
| 「〇〇様」「〇〇さん」 | 名前の部分だけ（「お客様」「皆様」は隠さない） |
| 「氏名」「住所」などの欄 | 見出しの右／下の入力欄の中身 |
| 必ず隠したい言葉 | 画面で登録した名前・会社名など |

一度個人情報と判定した文字は、動画の他の場面に出てきても隠します（スクロールで見出しが消えた後なども）。

## 注意

- 自動判定は100%ではありません。**最後は必ず目で確認**してください。
  特に「見出しのない場所に出てくる人の名前」は見つけにくいので、
  よく出る名前（顧客名・スタッフ名）は「必ず隠したい言葉」に登録しておくと確実です。
- 処理時間の目安：1分の動画で1〜2分ほど（「文字を読む間隔」を1秒にすると速くなります）。
- アップロードした元ファイルは処理後すぐ消えます。仕上がりは「削除」ボタンで消せます（`work` フォルダに残ります）。

## 中身（分かる人向け）

- OCR：PaddleOCR の PP-OCRv5 モデルを RapidOCR（onnxruntime）で実行
- 判定：日本語向けの正規表現＋見出し位置のルール（`masker.py` の `PATTERNS` / `LABELS` で追加可能）
- 画面：Flask（`app.py`）、動画処理：OpenCV＋ffmpeg
- 必要なもの：Python 3、ffmpeg（`brew install ffmpeg`）
- コマンドで1本処理：`.venv/bin/python masker.py 入力.mp4 出力.mp4`
